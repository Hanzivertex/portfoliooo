# Hanzi Vertex Digital — Free Portfolio

A premium one-page portfolio for:
- AI video creation
- AI clone generation
- Video editing
- Prompt engineering

## Quick customization

1. Open `index.html`.
2. Replace the demo project cards with your own `<video>` elements or thumbnails.
3. Update the email, WhatsApp and Instagram links near the bottom.
4. Replace `assets/profile-reference.png` if you want a different visual.

## Free publishing

### GitHub Pages
1. Create a free GitHub repository.
2. Upload all files in this folder.
3. Go to Settings → Pages.
4. Select the main branch and `/root`.
5. GitHub will give you a free `github.io` website URL.

### Netlify
Drag this folder into Netlify's deploy area for a free site URL.

## Color direction

The design uses the visual language from the supplied Instagram screenshot:
